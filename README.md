# College Ticketing System

A simple Python-based College Ticketing System for managing college-related issues and requests.

## Features

- Create new tickets
- View all tickets
- Update ticket status
- Search tickets
- View ticket statistics
- Exit the system

## Technologies Used

- Python

## How to Run

1. Download or clone this repository.
2. Open Ticketing_System.py.
3. Run the Python file.
4. Follow the menu options displayed on the screen.

## Project Purpose

This project helps manage college complaints and service requests such as IT issues, projector problems, and maintenance requests.
